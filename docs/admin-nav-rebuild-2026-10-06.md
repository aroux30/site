# بازسازی ناوبری پنل ادمین — ۲۰۲۶-۱۰-۰۶

**دستور کاربر:** منوی ادمین ۴۴ آیتم تخت و بی‌نظم بود (تکراری، بدون دسته‌بندی، بدون
زیرمنو). باید گروه‌بندی شود. ۱۰ ریپازیتوری مرجع ادمین داده شد (Refine، react-admin،
Ant Design Pro، TailAdmin، shadcn-dashboard، CoreUI، Tabler، Sakai، Gentelella،
vue-element-admin) — **بدون کلون**، فقط از طریق GitHub API بررسی شدند.

## الگوهای اقتباس‌شده از ۱۰ ریپو

- گروه‌بندی config-محور (shadcn-dashboard / CoreUI)
- باز شدن خودکار گروه فعال (Refine / Gentelella)
- ذخیرهٔ وضعیت باز/بسته در localStorage (Gentelella) — کلید `admin-nav-open-group`
- دراور موبایل با بستن خودکار بعد از ناوبری (TailAdmin)
- active trail با prefix + استثنای والد وقتی فرزند فعال است (vue-element-admin `meta.activeMenu`)

## رفتار کلیدی

- **آکاردئون یک‌در-هر-زمان**: باز کردن گروه جدید، قبلی را می‌بندد
- **گروه صفحهٔ جاری خودکار باز می‌شود** — هرگز روی صفحه‌ای با گروه بسته فرود نمی‌آیید
- **والد/فرزند**: `/admin/data-exchange` و `/admin/data-exchange/export` دقیقاً
  یک ردیف را هایلایت می‌کنند (قبلاً هر دو روشن می‌شدند — باگ flat list)
- **کنتراست**: جفت هم‌توکن `bg-foreground/10 + text-foreground` حفظ شد
  (درس حادثهٔ dark-on-dark ۲۰۲۶-۱۰-۰۴)
- **دسترس‌پذیری**: `aria-expanded`, `aria-controls`, `aria-current="page"`,
  `inert` روی پنل‌های بسته (لینک‌های کلیپ‌شده فوکوس نمی‌گیرند)

## یافتهٔ جانبی (از قبل موجود — تسک جدا)

سرریز افقی ۱۸۴px در صفحات ادمین با جدول عریض در موبایل (viewport ۳۹۰ →
`scrollWidth=574`). روی بیلد قدیمی :3000 هم دقیقاً همان است؛ از این بازسازی
نیست. مقصر: جدول داخل `.overflow-x-auto` در RTL به چپ بیرون می‌زند
(`rect.left=-214`). فیکس تست‌شده: `dir="ltr"` روی اسکرولر + `dir="rtl"` روی
جدول. به‌عنوان task chip جدا ثبت شد.
