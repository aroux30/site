## ۲. ریشه‌یابی ۵-چرا (5-Whys Root Cause Analysis)

**باگ محوری وزنه ۹ (حل‌کننده Scoped CSS)**: جلوگیری از نشت کدهای CSS سفارشی وارد شده توسط کاربر در فیلدهای `custom_css` به سایر المان‌های بوم استودیو از طریق نگاشت استاندارد `{{WRAPPER}}` طبق قرارداد پورت المنتور.

1. **چرا کدهای CSS سفارشی در المنتور پرو از توکن `{{WRAPPER}}` استفاده می‌کنند؟**
   زیرا استایل‌های نوشته‌شده نباید به صورت سراسری کل صفحه را دستخوش تغییر کنند و باید محدود به همان المان باشند (`[data-element-id="..."]`).
2. **چرا ایجاد ماژول اختصاصی `scoped-css.ts` در لایبری بیلدر ضروری بود؟**
   زیرا قبل از این، کدهای CSS خام بدون جایگزینی ممکن بود مستقیماً تزریق شوند و هدر یا سایدبار استودیو را دچار اختلال کنند. با تابع `resolveScopedCss` این نگاشت به طور قطعی ایزوله شد.
3. **چرا نگاشت حروف بزرگ و کوچک و فاصله‌دار در `{{ wrapper }}` مهار شد؟**
   با رجکس `/\{\{\s*WRAPPER\s*\}\}/gi` هرگونه نگارش با حروف کوچک یا بزرگ به صورت ایمن جایگزین سلکتور معتبر می‌شود.
4. **چرا خروجی‌های DOM فاقد نشت کلاس یا خطا باقی ماندند؟**
   زیرا در صورت ورودی خالی یا نامعتبر، یک رشته خالی برمی‌گردد و هیچ تگ خالی به DOM اضافه نمی‌شود.
5. **اصلاح ریشه‌ای اعمال‌شده در این دور**:
   - لایه لایبری: پیاده‌سازی `frontend/lib/builder/scoped-css.ts`.
   - لایه تست‌ها: افزودن تست واحد `builder-scoped-css.test.ts` و عبور کامل ۴۱۵ تست فرانت‌اند.

## ۳. تحلیل SWOT و ماتریس TOWS

### ۳.۱ تحلیل SWOT
- **نقاط قوت (Strengths)**:
  - امنیت کامل در برابر نشت کدهای CSS و حفاظت از محیط استودیو.
  - پاس شدن ۴۱۵ تست واحد Vitest و ۶۵۵ تست واحد Pytest.
  - تکمیل بی‌نقص زنجیره وزنه‌های ۰ تا ۹ تمرین پیش‌رونده.
- **نقاط ضعف (Weaknesses)**:
  - تحلیل نحوی پیشرفته قوانین CSS (مانند CSS Parser) برای خطایابی زنده سینتکس می‌تواند در آینده تعبیه شود.
- **فرصت‌ها (Opportunities)**:
  - ارائه کتابخانه کدهای CSS آماده و ترنزیشن‌های انیمیشنی برای طراحان وب.
- **تهدیدها (Threats)**:
  - استفاده کاربر از سلکتورهای `!important` درون کد سفارشی.

### ۳.۲ استراتژی‌های TOWS
- **SO**: بهره‌گیری از Scoped CSS برای طراحی المان‌های فوق‌سفارشی بدون نگرانی از تداخل استایل‌ها.
- **WO**: تعبیه ادیتور مینی‌کد همراه با شماره خط در تب پیشرفته بازرس.
- **ST**: تثبیت فیلترهای ضد XSS در تگ‌های کدهای سفارشی در لایه بک‌اند.
- **WT**: تست منظم استرس رندر استایل‌های سفارشی سنگین.
